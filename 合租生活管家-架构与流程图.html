二、费用 AA 分摊流程从垫付到结清全程留痕

核心目标：App 代替人开口催款，账单确认有超时兜底，月底结算自动合并互欠。

flowchart TD
    A["产生公共支出
例：室友垫付电费 200 元"] --> B["付款人「记一笔」
金额 / 类别 / 上传票据"]
    B --> C{"选择分摊方式"}
    C --> C1["全员均分"]
    C --> C2["自定义比例 / 指定金额"]
    C --> C3["部分成员参与
（出差者不参与）"]
    C1 --> D["生成待付账单
自动推送通知相关室友"]
    C2 --> D
    C3 --> D
    D --> E{"室友确认账单
（48h 超时默认确认）"}
    E -->|"有异议"| E1["发起异议 → 协商修改"] --> B
    E -->|"确认"| F["室友转账付款
可上传截图 / 标记已付"]
    F --> G{"全部付清？"}
    G -->|"否，临期未付"| H["付款人「一键催款」
委婉话术模板推送"]
    H --> F
    G -->|"是"| I["账单完结，留档可查"]
    I --> J["月底触发月度结算
汇总全员应收应付"]
    J --> K["债务简化
合并互欠，最少笔数多退少补"]
    K --> L["生成月度结算单
全员确认归档"]

分摊方式均分（绝对公平）/ 自定义比例（相对公平）/ 部分成员参与（出差豁免），覆盖合租主要争议场景。
超时默认确认防止「装死不确认」导致账单卡死，保证流程可推进。
一键催款委婉话术模板是产品的情绪价值核心：留面子、有据可查。
债务简化3 人以上互欠常见，合并后每人最多转一次账。

三、清洁值日闭环排班自动 + 执行留痕

核心目标：排班自动化、执行可视化、异常（换班 / 未完成）有正式处理通道。

flowchart TD
    A["户主设置清洁区域与标准
配置轮换规则（按周 / 顺序）"] --> B["系统自动生成排班表"]
    B --> C["前一日：预告提醒"]
    C --> D["当天早上：值日提醒"]
    D --> E{"值日人当天可做？"}
    E -->|"可以"| G["执行清洁 → 拍照打卡
全员可见"]
    E -->|"临时有事"| F["发起换班 / 代班申请"]
    F --> F1{"对方确认？"}
    F1 -->|"确认"| F2["排班自动互换"] --> G
    F1 -->|"拒绝"| D
    D -->|"超时未打卡"| H["二次提醒（升级）"]
    H --> I{"当日补做？"}
    I -->|"是"| G
    I -->|"否"| J["记录「未完成」
按公约约定条款处理"]
    G --> K["完成留档
计入完成率 / 按时率统计"]
    J --> K
    K --> L["下一周期自动轮转"] --> B

提醒节奏预告 → 当天 → 超时升级，递进式而非一次性打扰。
换班确认权责转移必须双方知情，避免「我以为你帮我做了」。
拍照打卡留痕 + 被看见，付出可视化本身就是激励。
未完成处理App 不内置惩罚，引用自家公约条款，App 只做中立的记录者。

四、退租结算流程钱清 · 事交 · 权转 · 数据留

核心目标：好聚好散——退租是矛盾最集中的场景，流程必须完整兜底。

flowchart TD
    A["成员发起退租
设定退租日期"] --> B{"有未付账单？"}
    B -->|"有"| C["限期结清
或协商转移给其他成员"]
    C --> D{"有未收款项？"}
    B -->|"无"| D
    D -->|"有"| E["确认收款到账
退租后保留收款入口"]
    E --> F["值日任务移交
剩余排班自动重排"]
    D -->|"无"| F
    F --> G["公共物品处置
个人归属物品登记处理方式
（带走 / 折价转让）"]
    G --> H{"是否户主？"}
    H -->|"是"| I["先转让管理员给其他成员"]
    H -->|"否"| J["移出合租空间"]
    I --> J
    J --> K["历史数据保留（只读）
退租完成，好聚好散"]

    classDef action fill:#e8f0fe,stroke:#4f7cff,color:#1a3a8f;
    classDef decision fill:#fef6e0,stroke:#f5a623,color:#8a5a00;
    classDef done fill:#e7f6ec,stroke:#34a853,color:#1d6b35;
    class C,E,F,G,I,J action;
    class B,D,H decision;
    class K done;
未收款保留入口「人走了钱没收回」是最高频纠纷，流程上必须兜底。
值日自动重排避免人走了排班表出现「幽灵岗」。
物品处置登记「那个锅是谁的」是退租经典争吵点，提前在流程里消化。
数据只读保留退租者可回查历史账单，防止后续扯皮无据。
